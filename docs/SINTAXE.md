# Como escrever as anotações

Cada linha do texto vira um pedaço do caderno. A barra de formatação do editor escreve esses símbolos para você, mas dá para digitar direto também.

## Títulos

| Escreva | Vira |
| --- | --- |
| `# Título` | Tópico principal, numerado 1.0, 2.0… |
| `## Subtítulo` | Subtópico 1.1, 1.2… |
| `### Título` | Sub-subtópico 1.2.1… |
| `? Pergunta` | Faixa com a pergunta-chave |
| `?? Pergunta` | Faixa clarinha, menor |

A numeração continua de uma página para a outra.

## Listas e texto

| Escreva | Vira |
| --- | --- |
| `- texto` | Marcador. 2 espaços antes = segundo nível, 4 espaços = terceiro |
| `1. texto` | Lista numerada |
| `! texto` | Termo importante (negrito na cor do modelo) |
| `> texto` | Observação rápida |
| qualquer outra linha | Parágrafo |

## Caixas

| Escreva | Vira |
| --- | --- |
| `>> Título \| texto` | Bloco de observação importante |
| `!!! Título \| texto` | Caixa de alerta |
| `?! Tema \| pergunta \| texto` | Seção "Você sabia?" numerada (001, 002…) |
| `@ 1822 \| evento` | Linha do tempo |
| `Tabela: legenda` | Legenda numerada (Tabela 1, Tabela 2…) da tabela logo abaixo |
| `\| a \| b \|` | Tabela; a primeira linha é o cabeçalho |

## Destaques dentro do texto

| Escreva | Vira |
| --- | --- |
| `**negrito**` | **negrito** |
| `*itálico*` | *itálico* |
| `__sublinhado__` | sublinhado |
| `==texto==` | marca-texto amarelo |
| `++texto++` | marca-texto na cor secundária do modelo |
| `{{termo}}` | negrito na cor principal do modelo |

## Imagens

Estas linhas são criadas pelo editor. Não precisa digitar.

| Linha | O que é |
| --- | --- |
| `[capa:ID]` | Capa do capítulo (fica logo acima de um `#`). Use "Capas dos capítulos". |
| `[imagem:ID \| legenda]` | Imagem no meio do texto, com legenda opcional. Use o botão de imagem ou Ctrl+V. |
